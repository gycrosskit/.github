# GY CrossKit

Focused cross-platform components for Kotlin Multiplatform apps.

## Libraries

| Project | What it provides | Platforms |
| --- | --- | --- |
| [Compose WebView](https://github.com/gycrosskit/compose-webview) | WebView for Compose Multiplatform | Android, iOS |
| [Live SDK](https://github.com/gycrosskit/live-sdk) | Tencent AtomicX live viewing integration | Android, iOS |
| [Toast](https://github.com/gycrosskit/toast) | Native short messages for Compose Multiplatform and Kuikly | Android, iOS, HarmonyOS |

## HarmonyOS ports

[Koin OHOS](https://github.com/gycrosskit/koin-ohos) and [Stately OHOS](https://github.com/gycrosskit/stately-ohos) are forks with HarmonyOS adaptations. See each repository's `OHOS_PORT.md` for the changes and setup.

For installation and platform requirements, start with the README in the relevant repository. Please open issues in that repository.
